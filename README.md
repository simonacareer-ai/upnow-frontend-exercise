# UpNow — frontend exercise starter

Blank Next.js 16 app for the frontend hiring exercise.

- [BRIEF.md](./BRIEF.md) — the task
- [API.md](./API.md) — endpoint contracts

```bash
npm install
npm run dev
```

- Next.js 16 (App Router) · React 19 · TypeScript · Tailwind 4
- UpNow brand tokens live in `src/app/globals.css`
- `src/lib/cn.ts` — `clsx` + `tailwind-merge` helper

Nothing else is set up. That is deliberate.
